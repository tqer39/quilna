# 出典文書の永続カタログ

[English](source-document-catalog.md) | [日本語](source-document-catalog.ja.md)

## 実装範囲

`workers/document-catalog.mjs` の内部クラス `DocumentCatalog` は、[Issue #74](https://github.com/tqer39/quilna/issues/74)の永続保存処理です。2人分の合成ユーザーと、ローカルMiniflareのSQLite-backed Durable Objectsで検証します。**本番の経路・認証・記事取得・ブラウザには未接続です。** 本番にカタログのbindingや共有設定は追加せず、本人限定環境は既存のリーダーとRSS配送キューを使います。ユーザー間共有や同期の完成ではありません。

呼び出し側が認可済みの範囲と正規化した出典URLごとに保存オブジェクトを選び、信頼できる `authorize` と `load` の接続処理を渡します。認可の結果は厳密に `true` である必要があります。範囲名・文書ID・版のhashは識別子であり、認証情報ではありません。取得・閲覧・履歴は保存領域の確認前に認可し、非同期処理後の返却前にも確認します。権限がない場合は文書の有無にかかわらず同じ利用不可エラーを返します。通信経路へ接続する前に、実際の出典共有方針による認可が必要です。検証用の合成IDと許可リストは本番認証ではありません。

取得処理に渡すのは出典URLと過去の原文・HTTP検証情報だけです。サーバー上で時間を制限して取得・本文抽出し、既存の公開アドレス・転送・応答上限を守り、検証済みの原文か対応する変更なしの結果を返す必要があります。ブラウザから送られた本文を、信頼できる共有出典として扱ってはいけません。原文の文書・版ID、表現のダイジェスト、コード範囲、形式版はブラウザと共通です。共通の書式検証はDOMに依存しません。個人の購読・保存／既読・訳文・引用・学習記録はカタログの項目に含めません。

## 永続化と回復

- 原文は24時間以内なら再利用します。明示的な更新は鮮度を無視します。1件の取得が30秒の永続的な処理権を持つ間、同時要求には再試行時刻付きの処理待ちを返します。呼び出し側の再試行が必要で、この処理自体にバックグラウンド実行や待機画面はありません。
- 通信とダイジェスト計算は保存トランザクションの外で実行します。ランダムな処理権トークンと期限を、本文版の保存・現在版の切り替えと同じトランザクションで確認します。期限切れや交代済みの処理は、遅い結果の保存や新しい処理権の解除をできません。期限後の新しい要求で回復できます。解除の保存も失敗した場合は期限後の回復に任せます。
- 不変版は元の取得時刻とカタログへの保存時刻を保持します。変更なしの更新確認では文書の確認時刻・編集版とHTTP検証情報だけを更新します。以前の表現へ戻った場合はその古い版を再利用します。取得失敗・容量不足・保存失敗でも過去の版を保持し、閲覧と更新を分離します。
- 各版を16,000 UTF-16単位の断片へ直列化し、断片と現在版の参照を同じトランザクションで保存します。読み込み時に長さ・出典／範囲／IDの参照・表現のダイジェストを検証します。未知の形式や破損時に空のカタログで上書きしません。破損した過去版を、元の表現に戻った際の現在版として採用しません。
- 現在の上限は1文書100不変版・直列化後のUTF-8で10,000,000バイト、1版4,000,000バイトです。超過時は根拠となる本文を黙って追い出さず容量不足を返します。履歴は20件ずつ、末尾の版IDを使って続きへ進みます。順序は最後の選択時刻ではなく最初の保存順です。

トランザクションは[Durable Objectsの保存仕様](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/)に従います。実行環境の固定データ検証では、分割本文の停止・再起動後の保持、合成ユーザーの同時要求が1回の取得にまとまること、条件付き更新、個人／共有範囲の分離を確認します。障害注入では、処理権の期限切れ・遅い結果、本文の変更・元に戻る場合、取得中の権限失効、途中書き込みの取り消しと再試行、件数／バイト上限、ページ送り、破損・未知の保存形式を扱います。ローカルの合成データによる検証であり、実ユーザー間共有やブラウザの受け入れとは区別します。

## 残る接続

信頼できるサーバー本文抽出、出典の共有／アクセス方針、認証付き通信経路を接続し、その後ブラウザの文書参照と独立した個人状態をつなぎます。配送を有効にする前に、出典別名、保持／訂正／削除、要求回数制限、運用時の回復を定義します。権限失効は以降の取得を止めますが、すでにブラウザへ渡したコピーを回収できません。権限確認と本文の公開は外部の権限保存領域との単一トランザクションではないため、接続時に方針の版と失効の境界を定義する必要があります。意図する共有範囲が明示されるまでは、現在の本人限定環境を維持します。オフライン用コピーと既存のブラウザ検索条件を保持し、この処理でブラウザ保存を置き換えません。
