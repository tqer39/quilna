# Quilnaの命名とドメインの採用判断

[English](branding.md) | [日本語](branding.ja.md)

## 決定とサービスのテーマ

2026-10-24、プロジェクトオーナーはサービス名に **Quilna（クイルナ）**、正式ドメインに **quilna.page** を採用しました。
テーマは、人間が情報を収集し、取捨選択し、考え、自分の教科書を編んで理解することです。
人間による選択と思考が中心であり、読むこと、リンクの収集、生成された要約の受け取りだけに限定しない名前を目指しました。

条件は、イカした響き、日本語で自然に4文字で読めること、英語でも読み方がぶれにくいことでした。
身近な単語、単語の連結による造語、意味のある頭字語も許容しました。
`learn`、`-ist`/`-nist`、`-ism`、TLDの単語の活用を検討しましたが、いずれも必須ではありません。
特に`learn`は、響きや独自性を制約しないよう、途中で必須条件から外しました。
日本語・英語での好ましくない連想や、既存サービスとの重複も確認対象にしました。

## 検討した候補

| 方向性 | 挙がった候補 | 検討の経過 |
| --- | --- | --- |
| 旧名称 | TsumikiText / 積み木テキスト | 英語圏では「積み木」の比喩を説明する必要がありました。 |
| 価値を直接表す名前 | Read & Reason、Curiosity Shelf、Study Folio | 初期候補。その後、短い造語と、人間が自分の教科書を編む広いテーマを重視する方向へ進みました。 |
| 書く・作る比喩 | Textsmith | オーナーが好意的に評価した方向性です。最終的にはQuilnaを選びました。 |
| 学習に関連する造語や接尾辞 | Lerismo、Lerista、`learn`、`-ist`/`-ism` | 読み方や連想を検討し、`learn`を必須にしない方針へ変更しました。 |
| 最終候補 | Quilna / クイルナ、quilna.page | 読み方・ドメイン・類似商標の検討後に採用しました。 |

Quilnaは、筆記具の **quill（羽根ペン）** を連想する造語として検討しました。
日本語は「ク・イ・ル・ナ」の4文字です。
英語の想定読みは **KWIL-nuh**、発音記号の目安は `/ˈkwɪlnə/` です。
これは綴りからの推定で、辞書に定着した発音や、英語話者による調査結果ではありません。
日本語の「キルナ」を含む別の読み方もあり得るため、採用した読みを一貫して示します。
`.page`は、サービス名に学習を表す単語を必須とせず、教科書やページの連想を補える点を評価しました。

## 類似商標の比較と採用判断

| 商標 | 登録内容・実際の使用について確認した内容 | 比較した点 |
| --- | --- | --- |
| Kirune | 日本の登録 **6681062**、株式会社テクノスピーチ。公式製品は歌声ライブラリ・キャラクターの **機流音（きるね）**。登録の参考称呼にはキルネ・キルーンがあります。 | `QUILNA`と`KIRUNE`は外観が異なり、クイルナとキルネは冒頭と末尾の音も異なります。歌声合成と教科書作成の用途は違いますが、登録には一般的なソフトウェア・電子出版物・関連役務も含まれます。 |
| KIRUNA | EU商標 **018736632**、SENER, INGENIERIA Y SISTEMAS, S.A.、第9・42類。ダウンロード可能ソフトウェア、コンテンツ・データ管理ソフトウェア、電子出版物などを含みます。具体的な現行製品の用途までは確認できませんでした。 | `QUILNA`と`KIRUNA`は冒頭の綴りが異なり、末尾`NA`は共通です。日本語のクイルナとキルナは音が比較的近く、Quilnaがキルナと読まれる場合は区別に不利です。想定する英語の`/kwɪl…/`は、地名Kirunaの辞書上の読みとも異なります。 |

出典：[Kiruneの登録情報](https://www.j-platpat.inpit.go.jp/c1801/TR/JP-2022-111541/40/ja)、[Kirune公式製品](https://www.voisona.com/song/artist/kirune_ja_JP/)、[KIRUNAのEU登録](https://euipo.europa.eu/eSearch/#details/trademarks/018736632)、[Kirunaの辞書項目](https://www.collinsdictionary.com/dictionary/english/kiruna)。

検討では、名前の類似性と、登録された商品・役務の類似性を分けました。
綴りや実際の用途の違いは区別する材料になりますが、その違いだけで法的に非類似と確定するわけではありません。
現在販売している製品の目的が違っても、広く登録された商品・役務の文言が重なる場合があります。
日本とEUの対象地域も別であり、意図した日本語の読みだけでEUの需要者の読み方は決まりません。
[特許庁の審査基準](https://www.jpo.go.jp/system/laws/rule/guideline/trademark/kijun/document/index/20_4-1-11.pdf)も参照しました。

こうした違いを確認したうえで、オーナーはQuilnaとquilna.pageを採用する判断を明示しました。
これは上記の調査範囲に基づく **プロジェクトとしての採用判断** として記録し、商標登録や非侵害の保証とは区別します。
称呼の類似検索に候補が出たことだけを、法的に類似するとの判定には扱っていません。

## 実施済みの改名と互換性

- [Quilna PR #52](https://github.com/tqer39/quilna/pull/52)でWeb・ログイン画面、npmメタデータ、Appleアプリ・ビルド成果物名、CIの参照、設定例、英日文書を更新しました。
- [terraform-github PR #1812](https://github.com/tqer39/terraform-github/pull/1812)で既存GitHubリポジトリを改名し、ホームページを`https://quilna.page`に変更しました。リポジトリの数値IDは維持しています。
- [terraform-github PR #1813](https://github.com/tqer39/terraform-github/pull/1813)でTerraform rootを`terraform/src/repositories/quilna`へ移しました。backend keyの`terraform-github/repositories/adaptive-textbook.tfstate`は維持し、移動によるインフラ変更がないことをCIで確認しました。

既存データと資源の識別を維持するため、従来のApplication Support保存先、Bundle ID、ブラウザ保存・暗号化の識別子、Worker/D1名は残しています。
これらは互換性のための内部識別子であり、別の公開サービス名ではありません。
過去の公開記録にある旧URLは、当時の証跡として維持しています。
改名のローカル検証とマージ後のmain CIは成功していますが、公開済みDevサイトの再デプロイは行っていません。
